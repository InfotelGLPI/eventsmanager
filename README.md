## EventsManager plugin for GLPI

[![License](https://img.shields.io/badge/License-GNU%20GPL%20v3-blue.svg?style=flat-square)](https://github.com/InfotelGLPI/eventsmanager/blob/master/LICENSE)
[![Web](https://img.shields.io/badge/Web-Infotel-blue.svg?style=flat-square)](https://blogglpi.infotel.com)
[![Translate](https://img.shields.io/badge/Translate-Transifex-cyan)](https://explore.transifex.com/infotelGLPI/GLPI_eventsmanager/)

Events Manager lets you track IT events (alerts, warnings, exceptions, information) separately from tickets in GLPI. Each event follows its own lifecycle (New → Assigned → Closed), supports threaded comments and asset associations, and can be turned into a ticket with a single click. Events can also be created automatically from mail collectors (via mail rules) or from RSS feeds through a periodic cron task.
